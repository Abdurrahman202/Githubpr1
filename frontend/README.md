# TaskFlow Frontend

Modern Next.js frontend for the Software Engineer Intern Technical Assignment.

## Stack

- Next.js
- React
- Bootstrap 5
- Custom CSS
- JavaScript

## Current screens

- Landing page
- Login
- Register
- Normal user task dashboard
- Administrator dashboard
- Drag-and-drop task board (frontend demo state)
- Create task modal (frontend demo state)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Important

This first frontend version uses local demo data. The next implementation step is to connect it to the separate backend API for:

- registration
- login/authentication
- role-based authorization
- task CRUD
- task assignment/reassignment
- persistent status changes
- database-backed task board
