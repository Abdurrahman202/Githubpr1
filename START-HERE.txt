TASKFLOW FULL-STACK — START HERE

1. Install Node.js 20+ and MongoDB (or use MongoDB Atlas).
2. Backend:
   cd backend
   copy .env.example .env       (Windows PowerShell: Copy-Item .env.example .env)
   npm install
   npm run seed:admin
   npm run dev
3. Frontend (new terminal):
   cd frontend
   copy .env.local.example .env.local   (PowerShell: Copy-Item .env.local.example .env.local)
   npm install
   npm run dev
4. Open http://localhost:3000

The admin account is created from ADMIN_EMAIL and ADMIN_PASSWORD in backend/.env.
Do not commit .env files.
